FREQUENTLY ASKED QUESTIONS

Everything You Need to Know

What makes Neima different from official Claude in Chrome? +

Neima introduces an interactive in-page 3D spatial companion that physically flies across coordinates, shoots luminous targeting lasers at interactive elements, and communicates in real time through floating speech bubbles. Furthermore, Neima is multi-model (Claude 3.7, Gemini 3.8, GPT-4o, and local Ollama), includes a 1-click table scraper, developer console error traps, and stores 100% of your data locally with zero cloud telemetry.

Do I need to pay for an API key to test Neima? +

No! Neima features a built-in Autonomous Local Engine (Simulation Mode) that lets you test full page navigation, table scraping, and Set-of-Marks indexing completely free without any API key. If you have your own Anthropic, Gemini, or OpenAI key, or run Ollama locally, you can plug it into Settings at zero additional cost.

Is my browsing data or personal information stored or tracked? +

Never. Neima collects zero analytics, telemetry, or user logs. API keys and personal autofill profiles are stored exclusively in your local Chrome browser storage (chrome.storage.local). Page screenshots and text are dispatched only to your designated model provider endpoint.

Can I approve actions before Neima clicks or types? +

Yes! Neima includes Human-in-the-Loop Smart Safety. By default, routine navigation executes seamlessly while sensitive actions (checkout buttons, payments, account deletions, password entry) pause automatically to request your explicit approval.
